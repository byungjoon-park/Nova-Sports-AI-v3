# NOVA Performance Report — STEP 18

## 목적

STEP 17에서 만든 퍼포먼스 계산 엔진의 결과를 리포트에서 설명 가능하게 표시한다.

## 리포트에 표시할 내용

1. 종합 퍼포먼스 점수
2. 각 세부 점수
3. 각 항목의 가중치
4. 최종 점수에 대한 기여도
5. 날짜별 종합점수 추이
6. 이전 측정값 대비 변화량
7. 측정 데이터가 없는 경우의 안내

## 기본 항목

- GPS 퍼포먼스
- 동작분석
- 점프/폭발력
- 훈련 수행도
- 회복 상태
- 컨디션

## 계산 설명

리포트는 실제 계산 결과를 그대로 보여주며,
임의의 점수를 새로 생성하지 않는다.

예:
세부점수 88 × 가중치 30% = 기여도 26.4점

모든 기여도를 합산하여 종합 퍼포먼스 점수를 표시한다.

## 추이

날짜별 데이터를 저장/전달할 수 있는 구조를 준비한다.
7일, 30일, 90일 등의 기간 필터는 기존 리포트 화면에 연결할 때 적용한다.

## 기존 기능 보호

이번 STEP 18에서는 기존 Dashboard page.tsx를 교체하지 않는다.
기존 테마, 언어, 피로도, GPS 공지사항은 변경하지 않는다.

실제 리포트 페이지에 연결할 때에도 기존 기능을 삭제하지 않고 필요한 영역만 추가한다.

## 언어

NOVA는 한국어와 영어만 지원한다.
일본어는 추가하지 않는다.
