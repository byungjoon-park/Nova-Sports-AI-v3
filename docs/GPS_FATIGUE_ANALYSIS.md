# NOVA GPS 피로도 분석 1단계

## 목적

GPS 세션의 이동거리, 고속주행, 스프린트, 가속/감속, 활동시간을 이용해 훈련부하 경고 수준을 산출한다.

### 결과

- `normal`
- `caution`
- `high`

### 중요한 원칙

이 분석은 GPS 기반 **훈련부하 경고**이며 의료적 진단이나 부상 진단이 아니다.

## 현재 기준

선수의 과거 세션 기준값이 있으면 상대비교를 우선 사용한다.

비교 가능한 기준:
- 평균/일반 이동거리
- 고속주행거리
- 최고속도
- 스프린트 횟수
- 활동시간

과거 기준이 없으면 절대적인 세션 부하 신호를 보조적으로 사용한다.

## 다음 연결

```text
GPS
 ↓
GPS Session Metrics
 ↓
Fatigue Analyzer
 ↓
normal / caution / high
 ↓
동작분석 결과
 ↓
재활 상태
 ↓
운동추천
```

이 파일은 1차 분석 엔진이며, 실제 서비스에서는 선수별 과거 데이터로 baseline을 자동 산출하는 기능을 추가한다.
