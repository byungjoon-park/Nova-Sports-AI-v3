# NOVA Performance Score — STEP 17

## 목적

기존 Dashboard의 표시값을 바로 변경하지 않고,
퍼포먼스 점수를 실제 입력 데이터 기반으로 계산할 수 있는 별도 엔진을 준비한다.

## 기본 계산 구조

- GPS 퍼포먼스: 30%
- 동작분석: 25%
- 점프/폭발력: 15%
- 훈련 수행도: 15%
- 회복 상태: 10%
- 컨디션: 5%

총합 100%.

## 계산식

각 입력값은 0~100으로 제한한 뒤:

`종합점수 = Σ(세부점수 × 가중치)`

로 계산한다.

## 리포트 표시

각 점수별로 다음을 기록할 수 있도록 한다.

- 세부 점수
- 적용 가중치
- 최종 점수 기여도
- 종합 점수
- 추후 날짜별 측정값

예:
GPS 88 × 30% = 26.4
동작분석 84 × 25% = 21.0
...

## 중요

이번 STEP 17에서는 기존 Dashboard의 87점 표시를 자동으로 교체하지 않는다.
계산 엔진만 추가한다.

실제 NOVA 데이터가 연결되고 검증된 후 Dashboard 및 Report에 단계적으로 연결한다.

## 주의

이 가중치는 개발용 초기 설정값이며 의학적 진단이나 검증된 스포츠과학 평가척도를 의미하지 않는다.
실제 서비스 적용 전 데이터 검증과 전문가 검토가 필요하다.
